
# ⚡ AsyncRay: Ультимативный Асинхронный Xray-Чекер

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![Xray-core](https://img.shields.io/badge/Xray--core-Supported-success)](https://github.com/XTLS/Xray-core)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**AsyncRay** — это высокопроизводительный скрипт для массовой проверки VPN-конфигураций из публичных подписок. Он не просто «пингует IP-шники», он **динамически генерирует конфиги, поднимает локальные прокси-ядра Xray и тестирует реальное HTTP-соединение**, обходя DPI и блокировки.

> 🛑 **Проблема:** 95% ссылок в публичных базах мертвы. Обычные чекеры показывают, что сервер жив, но интернет через него не работает из-за сброса соединения (Anti-probing) или отсутствия TLS-маскировки.
> 
> ✅ **Решение:** AsyncRay использует полноценное ядро Xray, эмулирует отпечаток браузера (`fp=chrome`) и проверяет фактическую отдачу пакетов (HTTP 204). Выживают только реально работающие серверы.

---

## 🚀Почему именно AsyncRay?

- **Популярные протоколы:** Поддержка **VLESS, VMess, Trojan и Shadowsocks**. Автоматическая расшифровка Base64 и парсинг любых подписок.
- **Обход защиты от парсинга** Скрипт автоматически применяет TLS-fingerprint (Chrome) и обфускацию `flow` (например, `xtls-rprx-vision`), чтобы сервера не сбрасывали тестовые соединения.
- **Поддержка нового поколения протоколов** Понимает не только `ws` (WebSockets) и `grpc`, но и новейший **Split HTTP (`xhttp`)**.
- **Ассинхронность** Благодаря асинхронной архитектуре и семафорам, скрипт проверяет десятки узлов параллельно, создавая изолированные порты для каждого воркера.
- **Умная сортировка:** На выходе вы получаете чистый файл `good_proxies.txt`, где самые быстрые серверы находятся на самом верху.



## 🛠 Установка и Запуск

**1. Клонируйте репозиторий:**
```bash
git clone [https://github.com/CookieCompiler/AsyncRay.git](https://github.com/CookieCompiler/AsyncRay.git)
cd AsyncRay

```

**2. Установите зависимости:**

```bash
pip install -r requirements.txt

```

**3. Установите ядро Xray:**
Скачайте бинарный файл `xray.exe` (для Windows) или `xray` (для Linux) из [официального репозитория Xray-core](https://github.com/XTLS/Xray-core/releases) и поместите его **в корневую папку** проекта (рядом с `main.py`).

**4. Запуск:**

```bash
python main.py

```

После завершения работы в папке появится файл `good_proxies.txt` с готовыми к использованию ссылками. Просто скопируйте их в ваш клиент (v2rayN, NekoRay и др.).

## For developers:

Проект построен с упором на отказоустойчивость и масштабируемость:

* **Удобное добавление протоколов** Маршрутизация генерации конфигураций (`outbound_settings`) в зависимости от протокола, что позволяет легко добавлять новые форматы (например, Hysteria2) в будущем.
* **Изолированные порта:** Каждый воркер получает уникальный порт (10800 + index) и временный `.json` конфиг, исключая конфликты при параллельном запуске процессов через `asyncio.create_subprocess_exec`.
* **Ошибка с одной ссылкой не повлияет на другие процессы:** Блоки `try/except` гарантируют, что битый Base64 или таймаут соединения убьют только конкретный таск, а не весь скрипт.
